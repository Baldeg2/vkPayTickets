# VK Ticket Bot для мероприятий ВШЭ

MVP бота для продажи билетов на мероприятия внутри ВШЭ.

## Запуск
pip install -r requirements.txt
Впиши VK_TOKEN и GROUP_ID в config.py
python bot.py

## Что умеет
Список мероприятий
Покупка билета (заглушка оплаты)
Мои билеты с уникальным кодом
Админ-команда добавления мероприятий
