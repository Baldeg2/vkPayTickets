
# VK Ticket Bot для мероприятий ВШЭ (MVP)

Бот для продажи билетов на мероприятия внутри ВШЭ через личные сообщения ВКонтакте.

## Возможности
- Список актуальных мероприятий
- Покупка билета с заглушкой оплаты
- Уникальный код билета для входа
- Просмотр своих билетов
- Админ-команда добавления мероприятий

## Установка и запуск

### 1. Установить зависимости
pip install -r requirements.txt

### 2. Создать сообщество ВК и получить токен
- Создай сообщество (vk.com/groups), тип "Публичная страница"
- Управление -> Работа с API -> Создать ключ
- Права: "Управление сообществом", "Сообщения сообщества"
- Управление -> Сообщения -> Включить сообщения сообщества
- Управление -> Сообщения -> Настройки для бота -> Возможности бота
- Управление -> Работа с API -> Long Poll API -> Включить
- В Long Poll API отметить "Входящие сообщения"

### 3. Вписать токен и ID группы в config.py
VK_TOKEN = "твой_токен"
GROUP_ID = 242266466

### 4. Запустить
python bot.py

### 5. Узнать свой ID и стать админом
- В диалоге с ботом: /myid
- Впиши ID в ADMIN_IDS в config.py
- Перезапусти бота

### 6. Добавить первое мероприятие
/add_event День открытых дверей | 2025-12-01 | 0 | 50

## Команды

| Команда | Кто | Что делает |
|---------|-----|-----------|
| /start | все | Главное меню |
| 🎟 Мероприятия | все | Список мероприятий |
| #N | все | Купить билет на мероприятие N |
| 📋 Мои билеты | все | Показать купленные билеты |
| /myid | все | Узнать свой VK ID |
| /add_event ... | админ | Добавить мероприятие |

## Архитектура

- bot.py — обработка сообщений (UI-слой)
- database.py — SQLite, работа с данными
- payment.py — заглушка платёжной системы
- utils.py — хелперы (логирование, генерация кодов)
- models.py — доменные модели
- config.py — конфигурация

## Замена заглушки оплаты

В payment.py функция process_payment возвращает фейковый ID транзакции.
Для реальной интеграции достаточно заменить её тело на вызов ЮKassa / VK Pay.
